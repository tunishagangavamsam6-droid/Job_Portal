# Job Portal Management System

A full-stack web application designed for managing job postings, candidate applications, and recruitment workflows.

## 🚀 Features

- **User Authentication**: Secure user login, signup, and session management.
- **Job Management**: Create, edit, publish, and delete job postings.
- **Candidate Applications**: Apply for active job listings and track application status.
- **Recruitment & Interview API**: Integrated endpoints to manage interview scheduling and candidate evaluations.

## 🛠️ Tech Stack

- **Frontend**: React / TypeScript, Vite
- **Backend**: Node.js / TypeScript, Server runtime (Bun/Vite)
- **Database / Auth**: Firebase Integration
- **Styling**: Tailwind CSS

## 📋 Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [Bun](https://bun.sh/) or `npm` / `pnpm`
